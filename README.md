# 🏪 مشروع MADAR — تحسين أداء متجر التجزئة باستخدام منهجية Six Sigma (DMAIC)

> **مشروع تحليل وتحسين حقيقي** طُبِّق على متجر تجزئة بهدف رفع معدل تحويل الزوار إلى مشترين من خلال منهجية **DMAIC** المبنية على البيانات.

---

## 📌 ملخص المشروع

| العنصر | التفاصيل |
| :--- | :--- |
| **المنهجية** | Six Sigma — DMAIC |
| **القطاع** | تجزئة (Retail) |
| **المشكلة** | انخفاض معدل التحويل إلى **22%** في أوقات الذروة |
| **مستوى سيجما الحالي** | **0.7 σ** (في أوقات الذروة) |
| **الهدف** | رفع مستوى سيجما إلى **1.25 σ** وتحقيق معدل تحويل **≥ 35%** |
| **DPMO الحالي** | 241,964 |
| **DPMO المستهدف** | ≤ 105,650 |

---

## 🔍 المشكلة

في بيئة متجر تجزئة تم تحليل **1,000 تفاعل مع العملاء**، تبيّن أن:
- معدل التحويل ينخفض إلى **22%** خلال أوقات الذروة (12:00 - 14:00)
- **79%** من تباين معدل التحويل يُعزى إلى **ازدحام المتجر** وبطء الخدمة
- متوسط وقت عملية الدفع **9.62 دقيقة**، منها **3.54 دقيقة** انتظار قبل الخدمة
- **38%** من العملاء طلبوا منتجات غير متوفرة (نفاد مخزون)

---

## 📁 هيكل المشروع (DMAIC Phases)

```
📂 MADAR-DMAIC-Project
├── 📂 D1_Define        → ميثاق المشروع | SIPOC | VOC & CTQ | تحليل أصحاب المصلحة
├── 📂 D2_Measure       → بيانات تدفق العملاء | استبيانات VOC | أداء المناديب (A-E)
├── 📂 D3_Analyze       → Fishbone | 5-Whys | Hypothesis Testing | تحليل الهدر | ملخص الأسباب
├── 📂 D4_Improve       → اختيار الحلول | خطة التنفيذ | خطة التدريب (CCXP & ToT)
└── 📂 D5_Control       → SOPs | خطة التحكم | SPC Charts | نقل المعرفة
```

---

## 📊 النتائج الرئيسية لكل مرحلة

### 1️⃣ التعريف (Define)
- **خط الأساس:** معدل تحويل **22%** في الذروة، و**~60%** في الأوقات الاعتيادية
- **المستهدف (CTQ):** تحويل **≥ 35%** | انتظار **≤ 3 دقائق** | تفاعل الموظف **≥ 90%**
- **نطاق المشروع:** برامج التدريب وتحسين عملية الدفع وإدارة المخزون

### 2️⃣ القياس (Measure)
- **مستوى سيجما:** يتراوح بين **0.7 σ** (ذروة) و **1.75 σ** (اعتيادي)
- **رضا العملاء (VOC):** متوسط تقييم **3.27 من 5**
- **أبرز أسباب الفقد:** طول الانتظار، نفاد المخزون، ضعف تفاعل الموظفين

### 3️⃣ التحليل (Analyze)
- **الارتباط:** r = **-0.89** بين ازدحام المتجر ومعدل التحويل
- **R²:** الازدحام وحده يفسر **79%** من تباين التحويل
- **اختبار t-Test:** فارق معنوي بين ذروة (متوسط 47.1%، أدنى 22%) واعتيادي (60.2%) — p < 0.001
- **السبب الجذري:** بطء عملية الدفع + نقص التدريب المتخصص + إدارة المخزون

### 4️⃣ التحسين (Improve)
| الحل | التفاصيل | التكلفة |
| :--- | :--- | :--- |
| شهادة **CCXP** | تأهيل الموظف C كخبير تجربة عميل | 2,416 ريال (مستردة عبر هدف) |
| شهادة **ToT** | تمكين الموظف C من نقل الخبرة | مجاني (منصة هدف) |
| نظام **العمولات** | ربط الأداء بالحوافز المالية | — |
| **برنامج 9 أشهر** | تدريب الفريق (A, B, D, E) بمعدل ساعة/يوم | — |

### 5️⃣ التحكم (Control)
- **KPIs المراقَبة:** معدل التحويل يومياً، مستوى سيجما شهرياً، تغطية التدريب 100%
- **أدوات المراقبة:** SPC Charts | POS Reports | جلسة تحسين شهرية
- **ميثاق الاستدامة:** توثيق المعرفة + تدريب مدرب رديف بحلول الشهر السابع
